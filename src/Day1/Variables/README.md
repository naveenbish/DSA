# TypeScript DSA Interview Questions

## **1. Variables & Data Types**

### **Basic Questions:**

- What are the different ways to declare variables in TypeScript?
- Explain the difference between `let`, `const`, and `var`.
- What is type inference in TypeScript?
- What are the primitive data types in TypeScript?
- How does TypeScript handle `null` and `undefined`?

### **Advanced Questions:**

- What is the difference between `any`, `unknown`, and `never` in TypeScript?
- Explain the concept of union types with an example.
- How do you use type assertions in TypeScript?
- What is the difference between `null` and `undefined` in TypeScript?
- How do optional properties work in TypeScript interfaces?

## **2. Special Types (`any`, `unknown`, `never`)**

### **Basic Questions:**

- When should you use `any` in TypeScript?
- How is `unknown` different from `any`?
- What is the purpose of the `never` type in TypeScript?
- Give an example where a function returns `never`.

### **Advanced Questions:**

- What happens if you assign an `unknown` type to a variable without type checking?
- How can you handle `unknown` values safely in TypeScript?
- How does TypeScript infer `never` in conditional types?

## **3. Arrays & Tuples**

### **Basic Questions:**

- How do you declare an array in TypeScript?
- What are the different ways to define arrays in TypeScript?
- How does a tuple differ from an array in TypeScript?
- Can you define a tuple with optional elements?
- What happens if you try to access an out-of-bounds index in a tuple?

### **Advanced Questions:**

- How can you use rest parameters with tuples?
- What are readonly tuples in TypeScript?
- Can you destructure a tuple in TypeScript? Provide an example.
- What is the difference between `Array<T>` and `T[]` in TypeScript?

## **4. Objects & Interfaces**

### **Basic Questions:**

- How do you define an object type in TypeScript?
- What is an interface in TypeScript?
- What is the difference between an interface and a type alias?
- Can interfaces have optional properties? How do you define them?
- How do you create a readonly property in an interface?

### **Advanced Questions:**

- Can interfaces extend other interfaces? Provide an example.
- What are index signatures in TypeScript interfaces?
- How do you enforce a function signature in an interface?
- How does TypeScript handle excess properties in object literals?

## **5. Enums in TypeScript**

### **Basic Questions:**

- What is an enum in TypeScript?
- How do numeric enums work in TypeScript?
- What is the difference between numeric and string enums?
- Can enums have computed values?
- How do you get the enum key from a value?

### **Advanced Questions:**

- What are const enums in TypeScript?
- How does TypeScript handle reverse mapping in numeric enums?
- Can you use enums with bitwise operations?
